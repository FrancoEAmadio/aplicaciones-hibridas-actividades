# Ejercicio de React Router DOM

Frontend en React con React Router DOM para el API REST de la semana 09.

Vistas: Home, Login, Registro y NotFound.

## Uso

```bash
npm install
npm run dev
```

El API tiene que estar corriendo en el puerto 5000. En desarrollo Vite redirige `/api` a `http://localhost:5000` (ver `vite.config.js`).
